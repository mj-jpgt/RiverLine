## Gaps found (in existing gates, not introduced by this task)

1. **`pnpm test:offline` is a stub that fails by design** — the project's
   own named merge-blocker for the core offline requirement (AGENTS.md
   "Offline is a requirement, not a feature") currently has zero real
   assertions behind it. Every live-test procedure touching M2 inherits
   this as NO COVERAGE. Not a bug in this agent's scope to fix — T-C3's job
   — but worth stating plainly since it's the single biggest hole in
   `traceability.md`.
2. **Two cross-cutting legal/data-integrity rules have no owning task**:
   `calculations` immutability (AGENTS.md rule 10) and the backup/restore
   requirement (build spec §7.5) are not named as an acceptance criterion in
   any T-C/T-A task block in `specs/core/tasks.md`. They risk falling
   through every individual task's "acceptance check passing" gate unless a
   human adds them explicitly to a task or to a cross-cutting CI check.
3. **`specs/core/tasks.md` T-C3 doesn't explicitly test the per-field
   last-write-wins conflict behavior** that build spec §2 item 5 requires
   ("conflicts resolve last-write-wins per field with an audit entry") —
   T-C3's acceptance criterion only names "queue + idempotent sync." OT-4 in
   the live-test plan covers the intended behavior, but there's no
   task-level hook forcing an agent to build it, let alone test it.
4. Build spec §10.1 literally says "11-element assessment," but the
   verified data contract (`docs/data-contracts/sde-cost-tables.md`,
   itself already correcting an earlier build-spec error) says 12
   residential elements. I did not silently pick one — flagged it at the
   top of `live-test-plan.md` and made LT-1 record the actual count
   exercised rather than assume either number is right. This is exactly the
   kind of thing SUBAGENT.md says to flag rather than resolve unilaterally.
5. `scripts/check-contrast.mjs` covers token-level contrast but there is no
   equivalent automated check for tap-target size (48px/8px spacing) — FC-1
   in the live-test plan is currently human-only for lack of a script,
   unlike FC-2 (contrast) which already has one.
