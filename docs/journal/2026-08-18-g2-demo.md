1. **`scripts/db/seed-demo-scenario.mjs`**: a second, self-contained
   jurisdiction, "Riverline Training Demo," sanctioned explicitly by build

   environment"). RLS isolates it from every real jurisdiction the same way
   it isolates any two tenants (schema/core.sql's `jurisdiction_id`
   predicate, not a convention). Contains:
   - 3 users: `demo-assessor@`, `demo-official@`, `demo-admin@riverline-training.example`
   - 8 structures, "101" through "108 Training Flood Ct", `parcel_id` =
     `TRAINING-DEMO-0XX`, `prop_class` = `TRAINING-DEMO`, `notes` prefixed
     `[TRAINING DEMO]` (migrations/0006 added `structures.notes`, so this
     field exists to use)
   - a jurisdiction-scoped `cost_tables` row (`TRAINING-DEMO-v1`) with a
     `source_citation` stating in full sentences that the numbers are
     illustrative only and not from a licensed cost-estimating guide
     (docs/BLOCKERS.md B1)
   - an ordinance citation clearly marked "TRAINING SAMPLE, not legal text"
   - every state the task asked for: one structure not yet assessed, one
     mid-capture draft, one completed and calculated awaiting review
     (NOT_SD), one completed and calculated awaiting review (BORDERLINE),
     one adopted SD with an issued letter, one adopted NOT_SD with an
     issued letter, and one adopted then superseded (non-residential, to
     also exercise the 7-element list) showing the audit trail a real
     correction leaves behind.

     classification) is re-implemented byte for byte from
     `src/core/engine/{calculate,rounding}.ts` inside the script itself.
     Scripts under `scripts/` never import from `src/` anywhere in this
     codebase (no build step for a plain `.mjs`), so every calculation row
     is derived from a target ratio via the exact same formula, never
     hand-typed, which keeps it internally consistent with what
     `getReviewDetail()` would recompute live from the same
     assessment_elements, cost_table, and sq_ft.
   - Idempotent: every insert is guarded by a natural-key lookup
     (jurisdiction name, user email, structure parcel_id, assessment
     client_id, calculation count). Verified for real, not just asserted:
     ran it twice against local `riverline_dev` and again against
     `riverline_test`, and diffed row counts (identical both times).
   - Runs against `--test` (riverline_test), the default (`DATABASE_URL`,
     local dev), and `--live` (reads `.env.supabase`, builds
     `DATABASE_URL_SESSION + "?sslmode=no-verify"`, the same pattern
     `docs/journal/2026-08-18-f1-registry.md` and
     `.scratch-f2/probe-users.mjs` already established for this repo).
     Letters are archived through a minimal local re-implementation of
     `src/shared/storage`'s two drivers (a local `uploads/<key>` write, or
     an `@supabase/supabase-js` upload for `--live`/`STORAGE_DRIVER=supabase`),
     using the exact same storage key convention
     (`letters/<jurisdictionId>/<letterId>.html`) the real
     `src/modules/a1-letters/actions.ts` uses, so the real app reads these
     back through `app/letters/` with no special-casing.

## Copy sweep: before and after (representative, not exhaustive; roughly 80 strings changed across 34 files)

Quoted strings below are the literal old and new text, including any
punctuation that was actually there; only the connecting prose around them
is mine.

- `"Network error — check your connection and try again."` becomes
  `"Network error. Check your connection and try again."` in 13 files:
  CostTableForm, JurisdictionSettingsForm, AdoptAction,
  OverrideElementControl, OverrideValueControl, SupersedeAction,
  EstimatesSearch, ConfirmEstimateForm, EstimateUploadFlow,
  IssueLetterAction, OrdinanceForm, LoginForm, and OccupancyEditor.
- `"Borderline — requires review"` becomes `"Borderline, requires review"`
  (app/determination/page.tsx).
- `"OK — active version {v}"`, `"OK — on file"`, and `"OK — configured"`
  become `"OK, active version {v}"`, `"OK, on file"`, and
  `"OK, configured"` (app/admin/page.tsx).
- `"Calculations cannot run — every assessment will show ... (see docs/BLOCKERS.md B1) until..."`
  becomes `"Calculations cannot run. Every assessment will show ... until a
  table is loaded here. See docs/BLOCKERS.md B1."`, with the same pattern
  applied to the ordinance-citation and appeal-window readiness rows.
- `"Residential — $ per square foot, all 12 required"` and
  `"Non-residential — $ per square foot, all 7 required"` become
  `"Residential: ..."` and `"Non-residential: ..."` (CostTableForm.tsx).
- `"Letterhead name — shown at the top of determination letters (optional)"`
  becomes `"Letterhead name (shown at the top of determination letters,
  optional)"`, with the same rewrite applied to the address-lines and
  ICC-paragraph labels.
- A bare em dash used as a table "no value" placeholder,
  `n === null ? "—" : ...`, becomes `n === null ? "N/A" : ...`
  (app/determination/page.tsx).
- `"This is the official finding of record — read-only."` becomes
  `"This is the official finding of record, read-only."`
  (app/determination/[clientId]/page.tsx).
- `"This cannot be undone" — a mistaken determination...` becomes
  `"This cannot be undone." A mistaken determination...` (AdoptAction.tsx).
- The water-depth-source suffix, `` ` — ${WATER_DEPTH_SOURCE_LABELS[...]}` ``,
  becomes `` ` (${WATER_DEPTH_SOURCE_LABELS[...]})` ``
  (app/determination/[clientId]/page.tsx).
- The `"— superseded"` tag becomes `"(superseded)"`
  (app/estimates/[clientId]/page.tsx).
- `"Skip automatic text reading — enter values by hand"` becomes
  `"Skip automatic text reading. Enter values by hand"`
  (EstimateUploadFlow.tsx, plus its e2e assertion in
  test/e2e/a4-estimates.spec.ts).
- `"Issuing creates the permanent record of this letter — an archived
  copy..."` becomes `"Issuing creates the permanent record of this
  letter: an archived copy..."` (IssueLetterAction.tsx).
- `"RiverLine never generates, guesses, or fills in placeholder ordinance
  text — the citation..."` becomes `"...placeholder ordinance text. The
  citation..."` (app/letters/[clientId]/page.tsx).
- `"No account? ... administrator — there is no self-signup."` becomes
  `"...administrator. There is no self-signup."` (LoginForm.tsx).
- `"one-time sign-in link — no password required."` becomes `"one-time
  sign-in link. No password required."` (app/login/page.tsx).
