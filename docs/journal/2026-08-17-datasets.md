## Critical finding for the build spec
Build spec §4 describes the SDE element structure as 8 items ("foundation, superstructure, roof, interior finish, electrical, plumbing, HVAC, built-in appliances"). The actual, verified SDE 3.0 structure (FEMA P-784, Table 3-6 p.3-39–3-41 and Table 3-8 p.3-51) has **12 residential elements** (adds: doors and windows, cabinets and countertops, floor finish — and separates roof covering from superstructure and exterior finish from interior finish) and **7 non-residential elements** (collapses several residential categories into "Interiors"). This needs to be corrected in the build spec / schema design before the M3 engine is implemented, or SDE export/import will not match FEMA's own tool.

Also found: Hamilton County's parcel data has no field labeled "market value" — only assessed values (`AVLAND`, `AVIMPROVE`, `AVTOTGROSS`). The build spec's `value_source` + official-override design already anticipates this ambiguity; it should be treated as the default path rather than an edge case, pending a human/legal ruling on whether assessed value can stand in for market value under Indiana law.
